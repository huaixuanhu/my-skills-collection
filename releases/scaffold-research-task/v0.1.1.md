# scaffold-research-task v0.1.1

Date: 2026-09-05

Status: validated local candidate

## Change

Standard generation and manual adaptation now have explicit separate routes. The generator and its validator retain the complete standard-layout contract. A manually adapted task can preserve existing paths, omit unused surfaces, use another implementation language, and record real responsibilities in its existing notes. Its acceptance follows the agreed layout and relevant host checks; it does not need a generator manifest or a false claim that the standard-layout validator passed.

Generator and validator token checks use the generator's `{{name}}` placeholder grammar. Nested JSON and ordinary brace pairs no longer count as unresolved tokens. Unknown template fields and unrendered placeholders still fail their applicable checks. Standard path safety, no-overwrite behavior, root-scope controls, and source/data/evidence boundaries remain in place.

## Compatibility

The manifest schema and standard template layout remain at schema 1. The validator accepts the known-compatible v0.1.0 and current v0.1.1 generator identities and checks document markers against the version actually recorded in the manifest. Unsupported identities still fail. Existing v0.1.0 artifacts keep their original provenance; they do not need to be relabeled or regenerated to adopt the updated skill.

This patch does not add a configurable path-mapping schema or make missing files valid under the standard profile. Use the manual route for a different accepted layout and record its actual validation evidence.

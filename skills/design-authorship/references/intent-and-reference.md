# Intent and Reference Alignment

Use this reference before material design work. Keep the alignment compact enough for the user to review.

## Design Contract

Establish or infer:

- artifact and work mode;
- audience and primary job;
- one primary task, claim, or decision;
- existing source of visual and interaction truth;
- desired emotional register expressed through concrete contrasts;
- factual, brand, licence, privacy, and accessibility constraints;
- output format, dimensions, platforms, and input methods;
- required real content and data density;
- visual patterns the result should not resemble;
- whether a concept-image pass would carry information that prose cannot carry reliably.

Avoid relying on `modern`, `clean`, `professional`, `premium`, or `beautiful` by themselves. Translate them into situated contrasts, such as calm private learning tool versus institutional education dashboard.

For material UI work, include the viewport and state contract from `ui-interaction.md`. Present one concise batch of unresolved questions. If the user explicitly delegates a choice, record the selected assumption and continue.

## Reference DNA

For each relevant screenshot, image, deck, product, or design system, extract:

- subject world and intended audience;
- macrostructure and reading path;
- hierarchy and density;
- alignment and spatial rhythm;
- typography roles;
- color roles rather than color values alone;
- shape, border, material, and depth language;
- imagery crop, scale, and relationship to text;
- interaction, motion, or slide-transition meaning;
- one memorable element;
- features to take;
- features to avoid or adapt.

Do not pixel-copy or convert one reference into a universal template. Separate brand consistency from model habit.

## Direction Setting

For greenfield or replacement work, follow an already-selected direction. Compare alternatives when a material design choice remains unresolved; two or three often suffice, but the decision determines the useful set. For each considered direction, retain the information needed to choose:

- a one-sentence visual and interaction thesis;
- reading path or task flow;
- rough composition;
- typography, color, and imagery roles;
- one signature element;
- principal usability or narrative risk;
- why it fits the actual content.

Alternatives should differ in ways that could change the design decision, such as spatial composition, reading path, density, symmetry, imagery relationship, information reveal, or interaction model. Do not manufacture differences to meet an axis count. Color alone does not create a different direction.

For an established-system extension, derive one direction from current tokens, components, interaction conventions, and representative screens. Identify only the gap that requires a new decision.

# Content-to-Form Mapping

Choose visual form after identifying the content relationship.

| Relationship | Useful forms to consider |
| --- | --- |
| Sequence or lifecycle | rail, timeline, continuous path, staged reveal |
| Causality or transformation | directed flow, input-output structure, funnel |
| Comparison | aligned columns, common baseline, matrix, small multiples |
| Hierarchy | tree, nested scope, tiered axis, indentation |
| Category | grouping, regions, labels, restrained color roles |
| State | local status marker, progress, state transition, emphasis |
| Evidence | chart, number, quotation, source image, screenshot |
| Primary claim | strong proportion, title, single image, direct annotation |
| System boundary | bracket, boundary line, swimlane, contained region |
| Relationship network | nodes and links only when connections are the subject |

These are candidates, not mandatory mappings. Select the form that makes the important relationship easiest to perceive in the intended medium.

## Container Test

Before adding a card or box, identify whether it carries at least one of:

- independent interaction;
- state containment;
- persistent boundary;
- direct comparison.

When none applies, prefer whitespace, alignment, rules, bands, axes, annotation, brackets, local background, imagery, or the data itself.

## Whole-Composition Pass

Individually justified containers can still fragment a continuous task or argument. Inspect the complete page or spread:

- Which region starts orientation, which carries the main task or claim, and which supplies supporting evidence? Does emphasis connect these regions without repeated competing entrances?
- Does equal size imply equal priority that the content does not have? Do separate boxes make related values harder to compare on a common baseline?
- Does padding or repeated framing consume space the actual content needs? Can a shared work surface, aligned rows, direct annotations, or a continuous band express the relationship more clearly?
- Is the next useful information or action discoverable from the current region? Can the user return to an earlier comparison without losing context?
- Does repetition preserve a learned role, while variation corresponds to a meaningful change in task, information, or state?

Removing borders alone may leave the same weak structure. Regroup, rebalance proportions, or change disclosure when the task requires it. A wireframe rectangle is a placement placeholder, not a requirement for a visible card. Preserve independent item collections when cards support browsing and selection.

## Shape and Visual Language

Give shapes, rules, typography, imagery, and motion roles within the selected language. Circles can distinguish an identity or control; a line can join related content or mark a boundary; a curve can express a continuous relationship. These are possibilities, not a shape dictionary or quota.

Keep recurring roles consistent across pages and states, while letting different tasks produce different compositions. Evaluate deliberate variation against the project's accepted intent using [project-design-context.md](project-design-context.md). Avoid swapping a repeated card template for a repeated editorial, circular, or asymmetric template.

## Dynamic Default Review

Review a familiar pattern when it appears, but retain it when context supports it. Ask:

- Does equal area imply equality that the content does not have?
- Does an arrow represent direction, transformation, or causality?
- Does numbering represent a real sequence?
- Does color encode category, state, scope, or emphasis that remains understandable without color alone?
- Does repetition reduce learning cost, or only make the page mechanically uniform?
- Could the same composition move to an unrelated industry with almost no change?

Do not turn the answers into fixed palette, font, radius, card-count, or layout bans.
